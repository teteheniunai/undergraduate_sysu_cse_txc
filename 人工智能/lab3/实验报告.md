###### 1.算法原理

- 首先使用A\*算法（依赖评估函数$f(n)=g(n)+h(n)$)，对A\*算法进行优化
  - 优点：时间相比IDA*更快，只要启发函数是可采纳的，就能保证找到最短路径
  - 缺点：空间复杂度高，需要保存所有生成节点
  - 数据结构：优先队列等
- 再使用IDA*算法（依赖评估函数$f(n)=g(n)+h(n)$)
  - 优点：空间复杂度较低，相比较A*不需要维护庞大的优先队列和closed Set
  - 数据结构：堆栈
  - 算法原理：结合DFS的空间效率以及A*的最优性，通过逐渐增加代价阈值，并使用带有深度限制的（DFS）来寻找最优解
- 启发函数首先选取**曼哈顿距离**
  - $h = \sum |x_{current} - x_{goal}| + |y_{current} - y_{goal}|$
- 可解性判断（**逆序数校验**）：防止算法在无解的棋盘上死循环导致内存溢出
  - 如果空格在倒数偶数行，逆序数必须是奇数
  - 如果空格在倒数奇数行，逆序数必须是偶数
- 棋盘使用二维数组存储

```python
class Node:
    def __init__(self, state, parent=None, g=0, h=0, move=""):  
        self.state = state  
        self.parent = parent  
        self.g = g         
        self.h = h          
        self.f = g + h      
        self.move = move        # 记录方向

    def __lt__(self, other):   #定义优先队列比较函数
        return self.f < other.f
```

- 使用逆序数校验是否存在解

```python
    def is_solvable(self):
        """判断初始状态是否有解"""
        flat_board = [num for row in self.start_state for num in row]
        inversions = 0
        zero_row_from_bottom = 0
    
        # 计算逆序数
        for i in range(len(flat_board)):
            if flat_board[i] == 0:
                zero_row_from_bottom = 4 - (i // 4)
                continue
            for j in range(i + 1, len(flat_board)):
                if flat_board[j] != 0 and flat_board[i] > flat_board[j]:
                    inversions += 1
    
        # 4x4 棋盘可解性规则
        if zero_row_from_bottom % 2 == 0:
            return inversions % 2 != 0
        else:
            return inversions % 2 == 0
```

- 计算曼哈顿距离

```python
      def manhattan_distance(self, state):
        """计算当前状态的曼哈顿距离"""
        distance = 0
        for r in range(4):
            for c in range(4):
                val = state[r][c]
                if val != 0:
                    goal_r, goal_c = self.goal_positions[val]
                    distance += abs(r - goal_r) + abs(c - goal_c)
        return distance
```

```python
      def get_neighbors(self, state):
        """获取当前状态所有可能的下一步状态"""
        neighbors = []
        zero_r, zero_c = -1, -1
    
        # 找到空格 (0) 的位置
        for r in range(4):
            for c in range(4):
                if state[r][c] == 0:
                    zero_r, zero_c = r, c
                    break
            if zero_r != -1: break

        directions = {
            "Up": (-1, 0), "Down": (1, 0), 
            "Left": (0, -1), "Right": (0, 1)
        }
    
        for move_name, (dr, dc) in directions.items():
            new_r, new_c = zero_r + dr, zero_c + dc
            if 0 <= new_r < 4 and 0 <= new_c < 4:
                # 交换 0 和相邻数字
                new_state = [list(row) for row in state]
                new_state[zero_r][zero_c], new_state[new_r][new_c] = new_state[new_r][new_c], new_state[zero_r][zero_c]
                neighbors.append((tuple(tuple(row) for row in new_state), move_name))
            
        return neighbors
```

```python
    def solve(self):
        """执行 A* 搜索算法"""
        if not self.is_solvable():
            return None

        start_h = self.manhattan_distance(self.start_state)
        start_node = Node(self.start_state, g=0, h=start_h)
    
        open_list = []
        heapq.heappush(open_list, start_node)
        closed_set = set()

        while open_list:
            current_node = heapq.heappop(open_list)

            if current_node.state == self.goal_state:
                path = []
                moves = []
                while current_node:
                    path.append(current_node.state)
                    if current_node.move:
                        moves.append(current_node.move)
                    current_node = current_node.parent
                # 反转路径，从目标往回溯
                return path[::-1], moves[::-1]

            closed_set.add(current_node.state)

            # 扩展子节点
            for neighbor_state, move_name in self.get_neighbors(current_node.state):
                if neighbor_state in closed_set:  #防止重复访问
                    continue

                g = current_node.g + 1
                h = self.manhattan_distance(neighbor_state)
                neighbor_node = Node(neighbor_state, parent=current_node, g=g, h=h, move=move_name)

                heapq.heappush(open_list, neighbor_node)

        return None
```

- DFSsearch函数

```python
    def _search(self, path_list, move_list, path_set, g, threshold):
        """IDA* 的核心深度优先搜索 (DFS)"""
        current_state = path_list[-1]
        f = g + self.manhattan_distance(current_state)

        # 如果当前 f 值超过了阈值，则截断，并返回这个 f 值作为下一次迭代的参考
        if f > threshold:
            return f
        
        if current_state == self.goal_state:
            self.final_path = list(path_list)
            self.final_moves = list(move_list)
            return "FOUND"

        min_threshold = float('inf') #初始化本轮阈值

        # 扩展子节点
        for neighbor_state, move_name in self.get_neighbors(current_state):
            #代替 A* 的 closed_set，避免回头路
            if neighbor_state not in path_set:
                path_list.append(neighbor_state)
                move_list.append(move_name)
                path_set.add(neighbor_state)

                # 递归搜索
                res = self._search(path_list, move_list, path_set, g + 1, threshold)

                if res == "FOUND":
                    return "FOUND"
                if res < min_threshold:
                    min_threshold = res

                # 回溯
                path_list.pop()
                move_list.pop()
                path_set.remove(neighbor_state)

        return min_threshold
```

```python
def solve(self):
        """执行 IDA* 搜索算法"""
        if not self.is_solvable():
            return None, None

        # 初始阈值为起点的启发式函数值
        threshold = self.manhattan_distance(self.start_state)
    
        path_list = [self.start_state]
        move_list = []
        path_set = {self.start_state}
    
        self.final_path = []
        self.final_moves = []

        # 迭代加深循环
        while True:
            res = self._search(path_list, move_list, path_set, 0, threshold)
        
            if res == "FOUND":
                return self.final_path, self.final_moves
            if res == float('inf'):
                return None, None
            
            # 更新阈值
            threshold = res
```

- 优化启发函数加入**线性冲突**：
  - 线性冲突原理：额外代价———每冲突一次，至少多走 2 步
  - 总代价 = 曼哈顿距离 + 2 × 线性冲突数

```python
def heuristic(self, state):
        """计算曼哈顿距离 + 线性冲突"""
        md = 0
        conflicts = 0
      
        # 曼哈顿距离
        for r in range(4):
            for c in range(4):
                val = state[r][c]
                if val != 0:
                    gr, gc = self.goal_positions[val]
                    md += abs(r - gr) + abs(c - gc)

        # 行线性冲突
        for r in range(4):
            row_tiles = []
            for c in range(4):
                val = state[r][c]
                if val != 0 and self.goal_positions[val][0] == r:
                    row_tiles.append((c, self.goal_positions[val][1]))
          
            # 检查是否有顺序颠倒
            for i in range(len(row_tiles)):
                for j in range(i + 1, len(row_tiles)):
                    if row_tiles[i][1] > row_tiles[j][1]:
                        conflicts += 1

        # 3列线性冲突
        for c in range(4):
            col_tiles = []
            for r in range(4):
                val = state[r][c]
                if val != 0 and self.goal_positions[val][1] == c:
                    col_tiles.append((r, self.goal_positions[val][0]))
          
            for i in range(len(col_tiles)):
                for j in range(i + 1, len(col_tiles)):
                    if col_tiles[i][1] > col_tiles[j][1]:
                        conflicts += 1

        # 每个冲突至少需要额外移动 2 步
        return md + 2 * conflicts
```

- 实验背景：TSP搜索空间随城市数量 $n$ 呈 $(n-1)!/2$ 指数级增长，属于 NP-Hard 问题
- TSP的解表示为**随机整数排列编码**
- 总距离计算公式：
$$L = \sum_{i=0}^{n-2} d(c_i, c_{i+1}) + d(c_{n-1}, c_0)$$其中 $d(c_i, c_j)$ 是城市 $i$ 与城市 $j$ 之间的**欧几里得距离**
- 适应度定义：$$Fitness = \frac{1}{L}$$
- 选择算子：**竞标赛选择法**，从种群中随机抽取k个个体，计算适应度保留最优者
  - 优点：相比轮盘赌选择，锦标赛选择能更好地保持种群多样性，且不容易陷入局部最优

```python
def load_tsp_data(filename):
    coords = []
    with open(filename, 'r') as f:
        lines = f.readlines()
        start = False
        for line in lines:
            if "NODE_COORD_SECTION" in line:
                start = True
                continue
            if "EOF" in line or line.strip() == "":
                break
            if start:
                parts = line.split()
                coords.append([float(parts[1]), float(parts[2])])
    return np.array(coords)
```

- 距离矩阵计算：欧几里得距离——平面上两点直线距离

```python
def calc_dist_matrix(coords):
    n = len(coords)
    dist_mat = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            dist_mat[i,j] = np.sqrt(np.sum((coords[i] - coords[j])**2))
    return dist_mat
```

##### 遗传算法类

- 初始化

```python
def __init__(self, dist_mat, pop_size=100, pc=0.8, pm=0.2):
        self.dist_mat = dist_mat
        self.n = len(dist_mat) #城市数量
        self.pop_size = pop_size #种群大小
        self.pc = pc  # 交叉概率
        self.pm = pm  # 变异概率
        #随机生成初始种群，sample——不重复，前一个range(self.n)是范围，后一个self.n是抽取个数
        self.pop = [random.sample(range(self.n), self.n) for _ in range(pop_size)]
```
- 适应度计算

```python
def fitness(self, route):
        dist = sum(self.dist_mat[route[i], route[(i+1)%self.n]] for i in range(self.n))
        return 1.0 / dist, dist
```

- 竞标赛选择：挑选优秀个体

```python
def selection(self, fitnesses):
        selected = []
        for _ in range(self.pop_size):
            candidates = random.sample(list(range(self.pop_size)), 3)
            best = max(candidates, key=lambda i: fitnesses[i])
            selected.append(self.pop[best])
        return selected
```

- PMX

```python
def pmx_crossover(self, p1, p2):
        #有分叉概率
        if random.random() > self.pc: return p1.copy()
        c = [None] * self.n
        start, end = sorted(random.sample(range(self.n), 2))
        c[start:end+1] = p1[start:end+1]
        
        for i in range(start, end+1):
            if p2[i] not in c:
                curr = p2[i]
                pos = i
                while c[pos] is not None:
                    # 找到p1中对应位置的值在p2中的位置
                    val_in_p1 = p1[pos]
                    pos = p2.index(val_in_p1)
                c[pos] = curr
        
        for i in range(self.n):
            if c[i] is None: c[i] = p2[i]
        return c
```

- 变异:倒置变异——将这两个位置之间的城市子序列进行反转

```python
def inversion_mutation(self, route):
        if random.random() < self.pm:
            start, end = sorted(random.sample(range(self.n), 2))
            route[start:end+1] = route[start:end+1][::-1]
        return route
```

- 进化：一代一代进化，直到找到最短路线

```python
def evolve(self, generations=500):
        best_dist_history = []
        best_route = None
        min_dist = float('inf')

        for g in range(generations):
            fits_and_dists = [self.fitness(ind) for ind in self.pop]
            fits = [f[0] for f in fits_and_dists]
            dists = [f[1] for f in fits_and_dists]
            
            # 记录最优
            current_min = min(dists)
            if current_min < min_dist:
                min_dist = current_min
                best_route = self.pop[dists.index(min_dist)]
            best_dist_history.append(min_dist)

            # 生成下一代
            new_pop = self.selection(fits)
            next_generation = []
            for i in range(0, self.pop_size, 2):
                p1, p2 = new_pop[i], new_pop[(i+1)%self.pop_size]
                next_generation.append(self.inversion_mutation(self.pmx_crossover(p1, p2)))
                next_generation.append(self.inversion_mutation(self.pmx_crossover(p2, p1)))
            self.pop = next_generation
            
            if g % 100 == 0: print(f"Gen {g}: Best Distance = {min_dist:.2f}")
            
        return best_route, best_dist_history
```

**算法优化**
- **精英保留机制**（resolve函数中）:交叉和变异具有破坏性，可能会“破坏”上一代极好解，使用精英保留可以确保最强基因永远存活参与繁衍

- 增大选择压力（selection函数）：将锦标赛选择的候选人数从 3 改为 5，让优秀的个体有更大的概率被选中交配，加快收敛速度

- **预先映射索引**：p2.index() 是一个 $O(n)$ 操作，嵌套在循环里，导致交叉操作变成了 $O(n^2)$，所以需要把“查表”速度提升几个量级

此时相比之前对于rw1642已能输出更多但是还是耗时比较久

- **2-opt局部搜素**：从盲目搜索到逻辑修正，在欧几里得空间里，任何交叉的两条边，总能通过反转它们之间的路径来缩短总距离
```pthon
def two_opt(self, route):
        best_route = route
        improved = True
        # 只进行有限次的尝试
        for _ in range(20): 
            i, j = sorted(random.sample(range(1, self.n - 1), 2))
            # 计算翻转 [i:j] 段前后的距离差 (只涉及 4 条边的变化)
            A, B = best_route[i-1], best_route[i]
            C, D = best_route[j], best_route[(j+1)%self.n]
            
            d_old = self.dist_mat[A, B] + self.dist_mat[C, D]
            d_new = self.dist_mat[A, C] + self.dist_mat[B, D]
            
            #翻转后距离更短就执行翻转
            if d_new < d_old:
                best_route[i:j+1] = reversed(best_route[i:j+1])
        return best_route
```

- 遗传算法参数对实验结果的影响分析

| 参数名称 | 增加参数值的正面影响  | 增加参数值的负面影响  | 对路线“交叉数”的具体影响 |
| :--- | :--- | :--- | :--- |
| **pop_size** (种群大小) | **搜索广度增加**：种群多样性更好，能从更多不同的初始路径开始优化，有效预防“早熟”并跳出局部最优。 | **计算开销线性增长**：每一代需要处理更多的交叉、变异和适应度计算，单代耗时显著增加。 | **决定了“解结”的概率**：较大的种群意味着在同一代中更有可能产生能抵消交叉线的基因组合，预防形成“死结”。 |
| **generations** (迭代次数) | **搜索深度增加**：使路径逐渐逼近全局最优解。 | **边际效应递减**：演化后期距离下降速度会极度放缓，长时间运行可能只带来极微小的精度提升。 | **决定了“解结”的深度**：交叉线的消除是一个循序渐进的过程。代数越多，算法越有时间通过“变异”捋直最后细小的交叉部分。 | 

> **交叉数与解质量**：在欧几里得 TSP 中，路线交叉代表了距离的冗余。交叉数越少，路径总长越接近最优解。

结果初步分析：

-  **准确性趋势**：
   - 在小型数据集 `wi29` 上，算法表现良好，误差控制在 5% 左右，路线基本成型
   - 在中型数据集 `qa194` 上，误差显著上升至 17.3%(改变pop_size和revolve次数会更加趋近)

-  **计算压力与性能瓶颈**：
   - **时间成本**：城市数量增加不到 7 倍（29 -> 194），耗时却增加了约 23 倍。
   - **大数据挑战**：在处理 `rw1621` 时，单代计算量巨大。由于 Python `index()` 操作的 $O(n)$ 复杂度导致算法在 174 秒内甚至无法完成有效的初步演化，第 0 代的距离与理论值相差悬殊，暴露出基础算法在大规模数据下的失效。

-  **内存稳定性**：
   - 内存占用随城市规模增长相对缓慢（106MB -> 109MB）
